Projects

  • UCAS Course Evaluation Helper

    An open-source browser userscript that reduces a recurring multi-step course evaluation workflow to a single click. Built with JavaScript and DOM automation; adapted within 24 hours of upstream system changes. 100+ stars on GitHub and widely installed via GreasyFork.

    • https://github.com/21White/UCAS-Course-Evaluate-SillyTool
  • Domain-Specific LLM Fine-Tuning and Intelligent Teaching System

    Core contributor on a Fudan University “MoE-Huawei” Intelligent Base program project. Applied LoRA/QLoRA parameter-efficient fine-tuning in PyTorch with a dual-channel architecture, cutting training cost by over 40%. Built a 100k-term domain knowledge base, raising BLEU-4 from 10.0% to 36.1% and reducing response latency from 3.2s to 1.2s. Deployed to both cloud (Open-WebUI) and on-device (PocketPal) targets.

  • Multimodal Student Posture Recognition System

    Core contributor. Fused MoveNet-based visual pose estimation with pressure-sensor data on an Intel edge platform, building a TensorFlow model for real-time detection of unhealthy sitting postures. Delivered the full embedded pipeline from multi-sensor acquisition through on-device inference to audio and mobile push alerts.
